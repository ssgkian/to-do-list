To-Do List CLI Program

Welcome to the **To-Do List CLI program** - a simple, user-friendly task manager designed for efficiency.  
With no learning curve, you can quickly add, view, edit, and mark tasks as complete.  
Your tasks are automatically saved to a file, so you never lose progress.

## Requirements
- Python 3.10 or higher installed

Run the project with:
```bash
python3 main.py
```
